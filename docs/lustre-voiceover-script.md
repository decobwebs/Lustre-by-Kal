# Lustre by Kal — Voiceover Script

*15 October 2026 · For the AI voice tool · Campaign: "The Group Chat"*

## How to use this

1. **Make each line on its own.** Paste one line at a time into the AI voice tool, generate it, and save it with the exact file name shown. One line = one file.
2. **Make 3 versions of each line** and keep the one that sounds most natural.
3. **Save as WAV** if the tool allows it, otherwise the highest-quality MP3. I'll convert and clean them.
4. **Paste only the words in the dark box.** The notes around it are for you, not for the voice.
5. Send me all the files together. They go in `video/assets/audio/voiceover/`.

## The voice

- **Who:** a warm Nigerian woman in her 30s or 40s. Confident, kind, smiling while she speaks.
- **How:** calm and unhurried. Never shouting, never "salesy". Like a trusted friend giving good advice.
- **Accent:** clear Nigerian English. **No Pidgin.**
- **Speed:** a little slower than normal conversation. Short lines need space to land.

**Tool settings (if your tool has them):** keep stability medium (about the middle), keep "style" or "exaggeration" low, and keep speed at normal or slightly slower.

## How to say the names

| Word | Say it like |
|---|---|
| Lustre | **LUSS-ter** |
| Kal | **KAL** (rhymes with "pal") |
| Radiant Lux | **RAY-dee-ent LUCKS** |
| Grace Lux | **GRACE LUCKS** |
| Bloom Lux | **BLOOM LUCKS** |
| WhatsApp | **WOTS-app** |

If the AI says a name wrong, try writing it the way it sounds in the box (for example "Lusster by Kal"). Keep the correct spelling in the file name.
